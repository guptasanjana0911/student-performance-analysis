# Student Performance Analysis using Multivariate Techniques

## Objective
Identify the underlying factors that influence student performance.

## Tools
R

## Methods
- Data cleaning and scaling
- PCA: first component explains 21.2% of variance
- Factor analysis: 3 latent factors (Academic Performance, Lifestyle/Social Behavior, Socio-Economic Background)
- K-means with 4 clusters (elbow method), validated with Ward's hierarchical clustering

## Key Findings
- G1, G2 and G3 grades are strongly correlated, so early grades predict final results
- Recommendations: early intervention, behavioral support, targeted mentorship
